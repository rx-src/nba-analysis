# NBA Player Stats Analysis (2026)

A data analysis project exploring NBA player performance using Python, pandas, and matplotlib

## What this project does

This project analyzes a dataset of 582 NBA players' 2026 season stats to answer a few questions.

- Who are the top scorers in the league?
- Who's the most efficient scorer, once accounting for playing time?
- Which teams have the most efficient roster on average?
- Is there a relationship between minutes played and points scored?

## Key Findings

- Luka Dončić
- Giannis Antetokounmpo
- Houstan Rockets
- More minutes played = more points scored, pretty much as expected. Not a perfect line though, some players with similar minutes score way more than others, probably comes down to efficiency

## Tools used

- Python
- pandas
- matplotlib

## How to run it
1. Clone this repo
2. Install dependencies: 'pip install pandas matplotlib'
3. Run 'python analysis.py'
